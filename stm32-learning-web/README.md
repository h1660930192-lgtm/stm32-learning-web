# STM32 入门学习助手

一个运行在浏览器里的交互式学习网站，帮助有 C 语言基础、学过 51 单片机但一段时间没写代码的学习者，从 C 语言恢复训练逐步过渡到 STM32 HAL 外设，再完成一个可写进简历的小项目。

它不是 STM32 固件，也不是普通静态文档，而是一个“学习仪表盘 + 每日任务 + 交互练习 + 项目路线”的前端应用。

## 适合人群

- 有一点 C 语言基础；
- 学过 51 单片机；
- 半年没有写 C，处于“看得懂但写不出来”的状态；
- 想快速学习 STM32CubeIDE、STM32CubeMX、HAL 库；
- 希望利用 AI 提高效率，但不想一上来被完整答案带着走；
- 想最终整理出一个可写进简历的 STM32 小项目。

## 技术栈

- React
- Vite
- TypeScript
- Tailwind CSS
- lucide-react 图标
- localStorage 本地进度保存

## 安装方法

```bash
npm install
```

## 启动方法

```bash
npm run dev
```

默认会启动 Vite 开发服务器，终端会显示本地访问地址，例如：

```text
http://localhost:5173/
```

## 构建方法

```bash
npm run build
```

构建结果会输出到 `dist/` 目录。

## 功能说明

- 首页 Dashboard：显示当前 Day、总进度、今日任务、阶段信息、最近学习记录和快速入口。
- 28 天学习路线：分为 C 语言恢复、STM32 外设入门、STM32 项目式训练三个阶段。
- 每日详情页：包含今日目标、概念、51 类比、STM32 实现、CubeMX 配置提示、最小代码框架、练习、自测问题、常见错误和学习笔记。
- 交互练习：默认隐藏答案，提供“我想自己做、一点提示、具体提示、参考代码、检查清单”五种操作。
- 每日小测：每一天 5 道题，包括单选、判断、简答、代码阅读、代码填空，提交后显示得分、错题解释和复习建议。
- 项目路线：围绕“轨道交通设备状态监测小系统”展示项目背景、功能、硬件模块、软件模块、外设对应关系、分阶段任务和简历描述模板。
- 学习进度保存：当前 Day、完成天数、小测得分、项目任务、学习笔记都会保存到 localStorage，刷新页面不会丢失。

## 学习原则

每个知识点都按这个节奏推进：

1. 先理解；
2. 再写代码；
3. 再检查；
4. 再做变式练习。

参考代码是校准工具，不是第一反应。真正目标是把你从“看懂代码”带回“能自己写代码”。
