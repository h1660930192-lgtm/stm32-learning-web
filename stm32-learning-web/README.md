# STM32 零基础入门学习助手

一个面向接近零基础学习者的交互式前端网站。它不假设你已经熟悉指针、数组、GPIO 或单片机，而是从最小 C 程序开始，逐步过渡到 GPIO、STM32 基础外设和综合小项目。

## 适合人群

- C 语言基础很薄弱，甚至忘记了 `scanf` 为什么要写 `&`
- 对数组、函数、指针、结构体需要重新学习
- 对 GPIO、引脚、电平、上拉下拉几乎没有概念
- 愿意快速补基础，最终目标仍然是入门 STM32

## 技术栈

## 功能说明

- 35 天路线，分为：
  - Day 1-10：C 语言重新入门
  - Day 11-17：单片机与 GPIO 基础
  - Day 18-28：STM32 基础外设
  - Day 29-35：综合小项目实战
- 首页包含当前基础诊断、零基础提示、总进度、今日任务和路线预览
- 每个 Day 页面包含：
  - 今天只要掌握的 3 件事
  - 初学者容易误解
  - 逐行代码解释
  - 关键符号说明
  - 分层练习提示
  - 学习笔记
- 练习默认隐藏答案，支持：
  - 解释题意
  - 一点提示
  - 更具体提示
  - 伪代码
  - 参考代码
  - 检查清单
- 每天 5 道小测，前 10 天明显降低难度
- 项目页按“最终效果、当前还不会没关系、先修基础、分阶段实现、简历模板”组织
- localStorage 保存：
  - `currentDay`
  - `completedDays`
  - `quizScores`
  - `notes`
  - `weakPoints`
  - `confidenceLevel`
  - `lastStudyDate`

## 学习原则

1. 不直接追求做大项目，先把基础补稳
2. C 语言先学到够 STM32 使用
3. STM32 入门优先抓 GPIO、串口、定时器、ADC
4. 看懂不等于会写，每天必须动手
5. AI 可以提示和检查，但不能直接替你完成
6. 先写错，再改对，是正常学习过程
